## Raman Xc Analyzer

Crystalline-fraction (Xc) maps from a grid of Raman spectra.

- macOS app (Apple Silicon and Intel), Windows app, or `index.html` in a browser.
- Export Image has a preview, size and text-size options, and copies to the clipboard (Ctrl/⌘+Shift+C).

The apps are not signed. See the README for how to open them the first time.
